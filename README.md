## 二、两个自建理论(简介)

### 螺纹圈套理论 (Screw-Thread Trap Theory)

解决「指针有几级」的问题。

- **数据是螺心(0 级)**,`&` 往外绕一圈 +1,`*` 退回一圈 −1
- 圈数 = 级数 = 自然数(0,1,2,3…),离散、可数、无上限
- **双关**:它也是「学习本身的圈套」——你以为懂了,却越钻越深

### 分块理论 (Block Theory)

解决「指针 `+1` 跳多远」的问题。

- **指针的指向类型决定一块多大,`+1` 走一整块**
- `p + 1` 跳的字节数 = `sizeof(*p)`
- **块大小 ≠ 指针大小**:块可以 60/20/4,指针自己恒为 8

> 两个理论是两条**独立的轴**:层级管「几级」,分块管「跳多远」,不能互相换算。

## 三、为什么要写这些

学 C 的时候,`sizeof(&arr)` 为什么是 8 不是 60?`*(*p+j)` 和 `*(p+j)` 差在哪?
`int**` 和 `int(*)[5]` 看起来一样,为什么行为不同?

这些问题,教科书常常只给结论,不给「为什么」。这个仓库记的是:
**我是怎么从「卡住」走到「想通」的**,包括我走过的弯路。
